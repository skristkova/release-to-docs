# Use dashboards

Dashboards show how your team handles calls: volume, missed calls, wait times and agent activity.

## Open a dashboard

1. Click **Reports** in the left menu.
2. Pick a dashboard, for example **Call volume**.
3. Set the date range in the top left.

## Export data

Click **Export to CSV** in the top right of any dashboard. The file downloads to your computer.
