# Route incoming calls

Decide who answers each incoming call.

1. Go to **Numbers** and click the number you want to set up.
2. Under **When someone calls**, pick **Ring a team**, **Ring one person** or **Play a menu (IVR)**.
3. Set what happens if nobody answers within the ring time: voicemail, another team, or an external number.
4. Click **Save**. The change applies to the next call.
